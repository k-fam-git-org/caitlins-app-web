# Runner duck idle frames

Copy the four transparent PNG frames exported from Krita into this folder using these exact names:

- `duck_idle_0000.png`
- `duck_idle_0001.png`
- `duck_idle_0002.png`
- `duck_idle_0003.png`

The app plays these frames at 6 FPS while the duck is resting in full-motion mode.

Keep all frames the same canvas size and alignment. The current duck display footprint is 44 × 44 CSS pixels.
